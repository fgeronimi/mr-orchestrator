# mr-orchestrator

Carnet de test : [kandev](https://github.com/kdlbs/kandev) suffit-il pour piloter des agents Claude Code comme une équipe, sur un vrai projet (memento, un RAG sur les *Pensées* de Marc Aurèle) ? Suivi dans [cmux](https://github.com/manaflow-ai/cmux), skills de [Matt Pocock](https://github.com/mattpocock/skills) en plugin.

| Fichier | Contenu |
| --- | --- |
| `docs/brief.md` | Le but et les décisions |
| `docs/kandev-test.md` | Critères, configuration cible, étapes |
| `docs/journal.md` | Observations, notes, verdict |
| `backlogs/` | Les besoins à faire traiter par les agents |

Les versions précédentes (skills `mro-*`, arbitre, rejeux) sont dans l'historique git, jusqu'au commit `d0af8f5`.
